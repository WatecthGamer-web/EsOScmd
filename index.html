EsOScmd 1.1 Alpha

EsOScmd Nedir?

EsOScmd, Windows'un CMD komut çalıştırma merkezi gibi tasarlanmış eğlenceli bir komut satırı simülatörüdür. Bir sistem yazılımı olmayıp harici bir betiktir; bilgisayara zarar veremez veya doğrudan sistem dosyalarıyla iletişim kuramaz. Ancak onu çalıştırmak tamamen senin elinde!

EsOScmd Açık Kaynak Kodu

EsOScmd'nin açık kaynak kodunu aşağıda inceleyebilir, dilediğin gibi kopyalayıp geliştirebilirsin:

import datetime
import os
import winsound

winsound.PlaySound("opening.wav", winsound.SND_FILENAME | winsound.SND_ASYNC)

simdiki_zaman = datetime.datetime.now()
tarih_str = simdiki_zaman.strftime("%d %B %Y")

print("Welcome to cmd at EsOS")
print("You can write command.")
print("Warning: This cmd is not completed.")
print(f"System Date: {tarih_str}\n")

while True:
    commander = input("€> ").strip().lower()

    if commander == "help":
        print("""
DATE      Showing date
NEWCMD    Starts a new cmd
CLEARDISPLAY  Cleaning words at the cmd
TIME      Showing time
VER       EsOS Commander v1.1 Alpha
EXIT      Exiting the EsOS cmd
""")
    elif commander == "date":
        guncel_tarih = datetime.datetime.now().strftime("%d %B %Y")
        print(f"\n{guncel_tarih}\n")
    elif commander == "time":
        saat_str = datetime.datetime.now().strftime("%H:%M:%S")
        print(f"\n{saat_str}\n")
    elif commander == "ver":
        print("\nEsOS Commander v1.1 Alpha\n")
    elif commander == "newcmd":
        print("\nStarting New EsOS cmd...\n")
        os.system("start cmd")
    elif commander == "cleardisplay":
        print("\n" * 30)
    elif commander == "exit":
        print("\nExiting the EsOS cmd...")
        winsound.PlaySound("closing.wav", winsound.SND_FILENAME)
        break
    elif commander == "python --version":
        print("\nidk\n")
    elif commander == "mal":
        print(f"\nSensin lan mal\n")
        winsound.PlaySound("closing.wav", winsound.SND_FILENAME)
        input("\nBilet kesildi, çıkış için bas enter'a...")
        break
    else:
        print(f"\nE404: '{commander}' is not found.\n")

input("\nPress Enter to exit")

What is EsOScmd?

EsOScmd is a fun command-line simulator designed like Windows CMD. It is an independent script rather than core system software; it cannot harm your computer or directly interact with system files. However, running it is entirely up to you!
