?? EsOScmd

EsOScmd, popüler Windows Komut İstemi'ne (cmd) benzer şekilde tasarlanmış, Python 3.13.15 ile yazılmış eğlenceli ve simüle edilmiş bir terminal arayüzüdür.


?? Güvenlik Notu: EsOScmd tamamen izole bir simülasyon ortamıdır. Bilgisayarınızla hiçbir iletişim kurmaz, dosya sisteminize veya sisteminize kesinlikle erişemez. Tamamen güvenle keşfedip oynayabilirsiniz!

?? Gereksinimler

Projeyi yerel bilgisayarınızda çalıştırabilmek için sisteminizde şu sürümün kurulu olması gerekir:


Python 3 (Önerilen sürüm: 3.13.15)

?? Kurulum ve Çalıştırma

Projeyi bilgisayarınıza indirip çalıştırmak için terminalinizde şu adımları izleyebilirsiniz:


Depoyu klonlayın veya indirin:


Bash

git clone https://github.com/watecthgamer-web/EsOScmd.git

Proje klasörüne girin:


Bash

cd EsOScmd

Terminali çalıştırın:


Bash

python main.py

(Not: Dosya adınıza göre komut değişiklik gösterebilir)
